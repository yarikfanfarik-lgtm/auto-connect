# Auto Connect 🎧⌚

Android-прототип системного popup-подключения устройств в стиле Apple.

## Что уже есть

- обнаружение Bluetooth-устройств рядом;
- каталог распознаваемых моделей по имени (`AirPods`, `Buds`, `Watch`, `WH-1000XM`, `Beats` и т. п.);
- разрешение **«Показывать поверх других приложений»**;
- foreground-сервис для продолжения обнаружения;
- нижняя popup-карточка поверх текущего приложения;
- кнопка **«Подключить»** и системное Bluetooth-сопряжение;
- автоматическое скрытие popup через 15 секунд;
- GitHub Actions, который сам генерирует Android-проект Flutter и собирает release APK.

## Важное ограничение Android

Обычное стороннее Android-приложение не получает публичного API, который гарантированно принудительно подключает любой Bluetooth-профиль (например, A2DP-наушники) без участия системного Bluetooth. Поэтому кнопка запускает системное сопряжение через `BluetoothDevice.createBond()`. После сопряжения подключение конкретного профиля оставляется Bluetooth-стеку Android. Это сделано специально, чтобы не использовать скрытые API и не получить нестабильную сборку.

## 3D-модели

Архитектура каталога уже отделена от Bluetooth-обнаружения: следующий слой можно сделать как каталог `modelId -> HTTPS GLB`, с локальным кэшем моделей. Для интерактивного GLB в Flutter подходит `model_viewer_plus`; он поддерживает glTF/GLB, вращение и AR. Перед добавлением тяжёлых моделей лучше хранить их отдельно от исходников приложения и скачивать по HTTPS по запросу.

## Сборка

После push в `main` workflow:

1. ставит Flutter stable;
2. выполняет `flutter create . --platforms=android`;
3. копирует Android Bluetooth/overlay слой;
4. запускает `flutter analyze lib`;
5. собирает `flutter build apk --release`;
6. сохраняет APK как artifact `AutoConnect-release-apk`.

APK можно скачать в GitHub Actions → последний успешный запуск → Artifacts.

## Почему карты из OurMaps не добавлены

Загруженный ранее проект OurMaps — отдельное Flutter-приложение. Для Auto Connect он не нужен: карты не используются в логике Bluetooth popup. Поэтому они не будут случайно тащиться в APK и увеличивать сборку или создавать лишние зависимости.
